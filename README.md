# FlashBasket - E-Commerce Platform

A full-stack e-commerce web application developed to provide users with a seamless online shopping experience. The platform enables users to browse products, search items category-wise, manage carts and wishlists, place orders, generate invoices, and perform secure online payments.

This project integrates product management, order processing, payment handling, and customer interaction into a single platform, providing a complete end-to-end e-commerce solution.
